The machine-readable source is **`docs/sms-templates.json`**. This page is generated from it; if they differ, the JSON wins. Rules for when each message is used: `docs/AGENT_SAFETY_RULES.md`.

## How to read the sizes

- **GSM-7** (plain English characters): 160 characters fit in 1 SMS; longer messages are split into 153-character segments.
- **UCS-2** (any character outside GSM-7): only 70 characters fit in 1 SMS, 67 per segment. **One such character switches the whole message to UCS-2**, so the cost can more than double.
- Spanish **á í ó ú** are **not** GSM-7. **ñ, é, ¿, ¡, ü are GSM-7**, so "mañana", "teléfono", "¿Preguntas?" cost nothing extra.
- Curly quotes (’ “ ”) and emoji also force UCS-2. Always use straight `'` and `"`.
- Sizes below use these sample values: clinic name "Community Health Clinic" (23 chars; the pilot clinic "Rhode Island Free Clinic" is 24), first name "Guadalupe", phone "(555) 555-0123", slot "Tue, Jun 3 at 10:00 AM" / "martes 3 de junio, 10:00 a. m.", location "Main St. office", specialty phrase " for your primary care appointment" / " para su cita de medicina general". A longer clinic name adds characters; code must re-measure the final text before sending.

## Spanish cost and the GSM-7 variants

Several natural Spanish messages contain á/í/ó/ú and cost **3–5 segments** instead of 2. Where possible, a **reworded** Spanish variant is given that stays in GSM-7. The variants are **not** accent-stripped text. Each one picks other correct words (for example "la cita que su proveedor *quiere* para usted" instead of "*pidió*", "mensaje *final*" instead of "*último* mensaje"). Every variant is correct, natural Spanish with the same meaning. No variant is offered where rewording would sound unnatural or change the meaning.

**Recommendation:** use the GSM-7 variants. They cost the same as English and read naturally. The clinician should confirm they sound right to the clinic's patients.

Templates with no variant are already GSM-7 in Spanish.

## Rules every template follows

- No diagnosis, referral reason, results or medicines (R3). The specialty appears in exactly one text, `slot_offer`, after identity is verified (owner decision 2026-11-14).
- `first_outreach` does not use the words AI/automated (owner decision 2026-11-14; disclosure is via the intake consent form, `help_reply`, and an honest answer whenever asked). Every other message that can start a conversation says it is automated (AI) (R5).
- Every outreach message tells how to opt out (STOP / ALTO) (R6).
- No links. No emoji.
- `emergency_reply`, `crisis_reply`, `stop_confirmation`, `help_reply`, `wrong_number` go out **at any hour**. Everything else respects 8 am–8 pm, Mon–Sat (R7).
